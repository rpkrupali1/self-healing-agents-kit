# Labs

Do [SETUP.md](../SETUP.md) first.

| Lab | Topic | Time |
|---|---|---|
| [Lab 1](lab-01-api-agent.md) | Build your own: an API test agent from an OpenAPI spec | 30 min |
| [Lab 2](lab-02-plan-and-generate.md) | Adopt what exists: Playwright's planner and generator | 30 min |
| [Lab 3](lab-03-self-healing.md) | Self-healing: break the app, triage, heal | 30 min |

Every lab works with **Claude Code, VS Code + Copilot, Codex or opencode**. Where the steps differ, the lab has a section for each tool.

The [prompts/](../prompts/) folder is the prompt library: the same prompts with no steps, for reuse on your own projects.
